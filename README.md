# ☕ Java Study Repository

This repository contains a collection of small Java projects, exercises, and experiments created for studying the Java language and the principles of Object-Oriented Programming (OOP).

The goal is to practice real code while exploring core concepts such as:

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
- Exception handling
- Basic file operations
- Graphical interfaces and simple applications

---

## 📁 Repository Overview

Each folder usually represents a separate project, exercise, or topic explored during the learning process.

Some projects may focus on:

- Basic Java syntax and control structures
- OOP modeling and class design
- Academic assignments
- Console applications
- GUI experiments
- Small games and logical challenges
- Data input, output, and persistence

The repository is organized as a personal study space, so the structure may vary from one project to another.

---

## 🛠 Requirements

To run the projects, you generally need:

- JDK 8 or newer
- A Java IDE such as IntelliJ IDEA, Eclipse, BlueJ, or VS Code
- Basic familiarity with the command line, if you prefer to compile manually

---

## ▶ How to Run

Most projects can be compiled and executed with commands similar to these:

    javac *.java
    java MainClassName

If the project contains packages or a specific folder structure, the commands may differ slightly.

When using an IDE, simply open the project folder and run the main class.
